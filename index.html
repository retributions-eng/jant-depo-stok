Online stok yönetim sistemi

İlk bağlantı ayarı

Bu dosya Supabase projenize bağlanmaya hazır. Aşağıdaki iki bilgiyi Supabase Dashboard → Project Settings → API bölümünden alıp girin. service_role / secret key kullanmayın.

Bu prototip ayarları yalnızca bu tarayıcıda saklar. Gerçek uygulamaya geçerken bunları GitHub koduna değil, güvenli yayın ayarlarına taşıyabiliriz. Publishable/anon anahtarı tek başına gizli değildir; veritabanı güvenliği RLS politikalarına dayanır.

Hesabına giriş yap

Jant depo kayıtlarına erişmek için oturum aç.

İlk kez giriş yapıyorsan Supabase Authentication → Users bölümünde mevcut kullanıcı için parola belirle veya parola sıfırlama akışını kullan. Buraya veritabanı parolasını değil, kullanıcı parolanı yaz.
